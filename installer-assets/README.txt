TerrificOCR - Fast PDF OCR for Windows
========================================

Thank you for downloading TerrificOCR!

INSTALLATION STEPS:
===================

1. Install Python 3.8+
   Download: https://www.python.org/downloads/
   IMPORTANT: Check "Add Python to PATH" during installation!

2. Install Tesseract OCR
   Option A: choco install tesseract
   Option B: Download from https://github.com/UB-Mannheim/tesseract/wiki

3. Run TerrificOCR-Setup-1.0.0.exe
   Follow the installation wizard

4. Run setup-helper.bat
   This will install Python dependencies automatically

5. Launch TerrificOCR
   Double-click the desktop shortcut!

FEATURES:
=========
- Single & batch PDF processing
- Multi-language OCR support
- Output preview with search
- Real-time progress tracking
- Multiple output formats (TXT, Markdown, JSON)
